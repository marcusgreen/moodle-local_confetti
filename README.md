# Moodle Confetti Plugin

This plugin adds joy and fun to your Moodle platform by displaying confetti effects when certain events occur.

## Features

- Displays confetti animations for various Moodle events
- Can be enabled or disabled for the frontpage
- Configurable confetti display on each login
- Various predefined confetti styles to choose from:
  - Realistic
  - Fireworks
  - Snow
  - School
  - Emoji
  - Text
- Configurable Moodle events that trigger confetti

## Installation

1. Extract the plugin archive to the `/local/` directory of your Moodle installation
2. Rename the folder to `confetti` (if necessary)
3. Visit the administration page in Moodle to complete the installation

## Configuration

After installation, you can configure the plugin under Site Administration > Plugins > Local Plugins > Confetti:

- Enable/disable confetti display on the frontpage
- Set whether confetti should be shown on every login
- Select a predefined confetti style
- Select specific Moodle events that should trigger confetti

## Preview

The plugin offers a preview function in the settings, allowing you to test the selected confetti effect.
